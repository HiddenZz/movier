# Movier

Самохостируемая платформа для поиска, скачивания и просмотра фильмов и сериалов.

## Окружение

| Компонент | Роль |
| --------- | ---- |
| **TMDB** | Поиск фильмов (через прокси), хранение части метаданных на бэкенде |
| **Torrent-бэкенд** | Агрегация раздач, скачивание, конвертация в HLS, хранение |
| **Backend** | Основной сервер |
| **Flutter (iOS / Android)** | Мобильный клиент |

## Возможности

### Поиск и избранное

- Поиск фильмов/сериалов по фильтрам и текстовому вхождению
- Управление избранным: добавление и удаление

### Детальная карточка

- Постер, название, год выпуска, страна и прочие мета-поля и тд
- Интерфейс аналогичен стандартным кинотеатрам

### Скачивание и воспроизведение

- Поиск раздачи по названию и доступности; 
- Отображение качества раздачи, число пиров/сидов, стаус по градации красный/желтый/зеленый. (при нажатии на статус, отображается описание пиров/сидов)
- Запуск скачивания на сервере
- Отслеживание прогресса скачивания и конвертации в HLS
- К одному фильму можно привязать несколько медиа (разные раздачи)
- Управление загрузкой: пауза, возобновление, отмена
- Скачивание готового контента на клиентское устройство
- Встроенный плеер с типовым набором функций кинотеатра

### AI-чат

- Чат-бот с рекомендациями фильмов
- Пользователь описывает желание → бот выдаёт подборку
