# PRD

Проект решает проблему поиска, воспроизведения и хранения торрент-контента. Доступность конетнта должна определяться наличием подключенных торрент-серверов либо набором фильмов загруженных на сервер приложения; Пользователь в праве решить скачать фильм на сервер, где фильм могут посмотреть и другие пользователи, если торрент не поддерживает реалтайм просмотр, либо загрузить на свое устройство, для локального просмотра;

## Ключевые сценарии использования

1. Поиск фильма в катлоге с фильтрацией и подборками, с возможностью посмотреть детальное описание, дотспуные сиды и качество соединения для просмотра
2. Поиск фильма с помощью АИ-агента, который может сформировать подборку по пожеланию пользователя или напомнить фильм по краткому описанию происходящего в картине
3. Реал тайм просмотр фильма с стриминга торрента
4. Скачивание и агрегация медиаконтентом на сервере - удаление, поставить на загрузку, проверка прогресса загрузки;
5. Скачивание фильма локально, с управлением контента локально(удалить, поделиться и тд)
